# Sample data

Only content that is legal to publish belongs here: open-licensed sources (e.g. PMC Open Access under CC BY, Wikipedia under CC BY-SA with attribution) or self-written material. Record the source and license of every file in this README.

The agent pipeline's sample lecture is `backend/tests/fixtures/sample_lecture.pdf`. It is original text written for this repo (no textbook and no classmate notes) and is rebuilt by `app.agent.sample_pdf.build_sample_lecture`.

Copyrighted textbooks, class slides, and classmates' notes go in `data/private/`, which is gitignored.
